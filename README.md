# Зерно и Ритм

Лендинг кофейни и бабл-ти бара. Проект на React, Vite и JavaScript с Tailwind CSS и `lucide-react`.

```sh
npm install
npm run dev
```

Vite напечатает адрес dev-сервера в терминале. Для production-сборки используйте `npm run build`. Для проверки кода используйте `npm run lint`.

Меню, цены и акции редактируются в `src/data/menuData.js`. Время акций и самовывоза рассчитывается по Москве. В корзине можно проверить скидку на первый демо-заказ с промокодом `COFFEE20`.

Демо-заказы сохраняются в браузере. Имя и телефон не записываются в браузерное хранилище. Номер в контактах указан для демонстрации. Иллюстративные фотографии Unsplash включены в проект, а интерактивный виджет Яндекс Карт загружается отдельно.

## Оплата и возвраты

### Локальная песочница без ключей

Запустите `npm run dev` и добавьте товар в корзину. Выберите оплату по QR-коду, заполните форму и нажмите «Перейти к оплате». Симуляция успешного платежа покажет подтверждение с ID транзакции. После этого нажмите «Провести тестовый возврат (Refund)» и проверьте журнал. QR действует 15 минут. Ссылка песочницы открывает страницу с номером и суммой заказа; кнопка симуляции остаётся в исходной корзине. Чтобы открыть ссылку на другом устройстве в той же сети, запустите Vite с `npm run dev -- --host` и оформляйте заказ по сетевому адресу, который напечатает Vite.

### Тестовый магазин ЮKassa

1. В кабинете ЮKassa нажмите «Добавить магазин» → «Тестовый магазин» → «Онлайн». При первой регистрации выберите переход к тестированию. После создания магазина скопируйте его `shopId` и выпустите секретный ключ в разделе интеграции. [Инструкция ЮKassa](https://yookassa.ru/docs/support/merchant/payments/implement/test-store)
2. Скопируйте `.env.example` в `.env` и заполните `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`. Оставьте `YOOKASSA_MODE=test`. При необходимости обновите `YOOKASSA_RETURN_URL`, сохранив фрагмент `#payment-return`. Ключи читает только сервер.
3. Запустите `npm run server` и `npm run dev` в отдельных терминалах. Платёжный сервер слушает `127.0.0.1:8787`. Из корзины откройте страницу оплаты ЮKassa, оплатите тестовой картой, дождитесь подтверждения в корзине, затем запросите возврат. **Тестовый магазин ЮKassa поддерживает карты и ЮMoney. СБП доступна в рабочем магазине.** [Тестирование ЮKassa](https://yookassa.ru/developers/payment-acceptance/testing-and-going-live/testing)

### Рабочий магазин

Для СБП используйте рабочий магазин с подключённой СБП, его ключи, `YOOKASSA_MODE=live` и HTTPS-адрес возврата. Установите `VITE_IS_DEV_MODE=false` и перезапустите Vite или пересоберите проект. QR содержит ссылку, которую ЮKassa привязала к номеру заказа и точной сумме. Корзина сверяет статус через сервер и показывает подтверждение после ответа ЮKassa. [Документация по СБП](https://yookassa.ru/developers/payment-acceptance/integration-scenarios/manual-integration/other/sbp)

В разработке и локальном предпросмотре Vite сам направляет `/api/` на платёжный сервер. При размещении сборки настройте такую же маршрутизацию на своём HTTPS-сервере. Для создания платежа передаются `checkoutKey` (UUID v4), `orderNumber`, `amount` в рублях, `items` (ключи вариантов и количество), `code`, `firstOrder` и `mode`. Сервер пересчитывает сумму по каталогу и сверяет её с корзиной.

Полный рабочий возврат инициирует оператор. Для вызова `POST /api/refund-payment` задайте `YOOKASSA_REFUND_TOKEN` и передайте его в заголовке `Authorization: Bearer …`. Тело запроса содержит `checkoutKey`, `payment_id` и `amount` в рублях. `checkoutKey` — ключ сессии, использованный при создании платежа. Сервер проверяет сумму и статус, а повторный запрос использует тот же ключ идемпотентности. Записи платежей и возвратов хранятся в `server/.payments/`. [Документация по возвратам](https://yookassa.ru/developers/payment-acceptance/after-the-payment/refunds)

На сайте отображается подтверждение платежа. Для рабочего запуска предусмотрите передачу заказа в кофейню и фискализацию, если она требуется для вашего магазина. Сейчас заказ хранится в браузере, а сервер хранит данные платежа и возврата.

Проверка серверного протокола с подменой ответов ЮKassa выполняется командой `node --test server/paymentServer.test.js`.
